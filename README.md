# 五子棋 v0.5.14

單機網頁五子棋：跟電腦下、兩人一起下、回頭看這盤、練習題。打開就能玩，不用安裝、不用註冊。介面有中文和英文。

## 怎麼玩

- 用瀏覽器打開網址就能下；手機可以「加到主畫面」，之後像 app 一樣從主畫面打開。
- 下棋：選對手（跟電腦下或兩人一起下）、規則、電腦有多強（入門、弱、中、強、最強），按「開始下棋」。
- 回頭看這盤：下完可以一步一步回頭看，電腦會幫你檢查整盤棋。
- 練習：進攻題和防守題，從入門到 5 步；還有連珠的 26 種開局。

## 規則

- 自由規則（預設）：15×15 棋盤，黑棋先下；橫、直、斜任一方向連成五子就贏，六子以上也算。
- 連珠規則：黑棋有禁手（三三、四四、長連），而且要剛好五子才算贏；白棋連成五子以上就贏。
- 棋盤下滿還沒人贏，就是和局。

## 隱私

帳號、分數和下棋紀錄只存在你這台裝置的瀏覽器裡，不會傳到任何地方。
